Sirius Mascot Image Files
=========================

Place the following PNG files in this folder (public/mascot/):

  home.png      - shown on the home/welcome screen (displayed at 200px width)
  subject.png   - shown on the subject selection screen (140px)
  lesson.png    - shown during a lesson/question (140px)
  result.png    - shown on the results screen (140px)
  wrong.png     - shown after a wrong answer (140px, falls back to lesson.png if missing)

All images should be square PNGs with a transparent background.
The component hides gracefully if any file is missing.
