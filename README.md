# Sirius — AI Teacher MVP

An AI-powered teacher for Class 6–7 students in India. Built with Next.js App Router, Tailwind CSS, and React Context. Runs entirely in the browser — no backend required.

## Stack
- **Next.js** (App Router, JavaScript)
- **Tailwind CSS**
- **React Context** for global state

## Folder Structure
```
app/          Next.js routes and layouts
components/   Reusable UI components
context/      React Context providers
data/         Static subject and lesson data
lib/          Shared utility functions
```

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
